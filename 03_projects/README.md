Project: Analysis of a series RLC circuit
📝 Description
This project performs the complete analysis of a series RLC circuit from the parameters entered by the user (R, L, C, frequency range).

It combines 4 Python frameworks:

NumPy: vector calculations (impedance, modulus, phase, resonance frequency)

SymPy: symbolic calculation (exact impedance formula, derivation to find resonance)

Matplotlib: plotting of the Bode diagram (modulus and phase)

CSV: export of data for external analysis (Excel, etc.)

🚀 Usage
python projet_RLC.py
Then enter the requested values:

Resistance R (Ω)

Inductance L (H)

Capacitance C (F)

Minimum frequency (Hz)

Maximum frequency (Hz)

Number of points

📊 Generated results
Display of the resonance frequency and minimum modulus

Symbolic formula of the impedance and derivative

Bode diagram (modulus + phase) saved as PNG

CSV export of data (frequency, modulus, phase)

🧰 Technologies used
Tool	                                      Role
NumPy                                     	Vectorized numerical calculations
SymPy                                      	Symbolic calculation (exact formulas)
Matplotlib	                                Graphical visualization
CSV	                                         Tabular data export
